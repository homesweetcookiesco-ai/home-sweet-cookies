# Home Sweet Cookies Website

A lightweight, responsive static website designed for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `home-sweet-cookies`.
2. Upload `index.html` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide a public URL.

## Connect a custom domain

After you own the domain, add it under **Settings → Pages → Custom domain** and then update your DNS records with your domain registrar using GitHub's instructions.

## Connect online ordering

Search `index.html` for:

`https://squareup.com/`

Replace it with your actual Square, Toast, Shopify, or other online-order URL.

## Customize

Search `index.html` for cookie prices, milk prices, Houston pickup details, email, social handle, and menu descriptions to edit them.

The entire site is contained in one HTML file, so it is intentionally easy to maintain.
